BESS（Battery Energy Storage System）调度的数据模型是 AI-EMS 中最关键的基础之一：它回答**问题里有哪些量、哪些是外部给定、哪些是状态与控制量，以及它们如何随时间演化**。下文按五个核心块展开：**系统结构**、**输入数据**、**状态**、**控制量**、**状态更新**；随后补充目标函数、约束与工程中的数据形态。

## 一、系统结构

典型结构可概括为：

```text
配电网
 ├── 负荷 (Load)
 ├── 光伏 (PV)
 ├── 电网购电 (Grid)
 └── 储能 (BESS)
```

在每个离散时刻 $t$，调度需要决定**储能的充放电功率**（大小与方向）。常见优化目标是：在**满足电气与安全约束**的前提下，**最小化购电成本**（或更一般的运行成本）。

## 二、输入数据（外部输入）

以下由环境或预测给出，**不是**当日调度可直接「改写」的量，但在滚动优化中可作为已知或随机参数处理。

### 电价

$\rho_t$：时刻 $t$ 的购电电价（$kWh$ 或等价货币单位）。

| 时刻  | 电价 $\rho_t$ |
| ----- | ---------------- |
| 0:00  | $0.2$          |
| 12:00 | $0.6$          |

直觉：**低价时段充电、高价时段放电**，以降低 $\sum_t \rho_t \cdot P_{\mathrm{grid},t}$。

### 负荷

$P_D(t)$：用户在时刻 $t$ 的有功需求（$\mathrm{kW}$）。

| 时刻 | $P_D(t)$ |
| ---- | ----------- |
| 8:00 | $120$     |
| 18:00 | $300$    |

### 光伏功率

$P_{\mathrm{PV}}(t)$：光伏在时刻 $t$ 的发电功率（$\mathrm{kW}$）。

| 时刻  | $P_{\mathrm{PV}}(t)$ |
| ----- | ---------------------- |
| 12:00 | $200$                |
| 18:00 | $0$                  |

### 净负荷

$$
P_{\mathrm{net}}(t) = P_D(t) - P_{\mathrm{PV}}(t)
$$

表示扣减光伏后，**母线侧仍须由电网与储能等平衡的净需求**。  
例：$P_D(t)=300\ \mathrm{kW}$，$P_{\mathrm{PV}}(t)=120\ \mathrm{kW}$，则 $P_{\mathrm{net}}(t)=180\ \mathrm{kW}$。

## 三、状态变量

状态刻画「当前可观测、且影响未来可行与代价」的信息。一种常用聚合为：

$$
s_t = \bigl(P_{\mathrm{net}}(t),\, \rho_t,\, \mathrm{SOC}_t\bigr)
$$

### 荷电状态 SOC

$\mathrm{SOC}_t$：时刻 $t$ 的相对电量，$\mathrm{SOC}_t \in [0,1]$（工程上常收紧为 $[\mathrm{SOC}_{\min}, \mathrm{SOC}_{\max}]$）。

| $\mathrm{SOC}$ | 含义   |
| ---------------- | ------ |
| $1.0$          | 满电   |
| $0.5$          | 一半   |
| $0.0$          | 放空（通常禁止触及） |

### 电价与净负荷在状态中的角色

- $P_{\mathrm{net}}(t)$：反映净功率缺口，直接影响功率平衡与线路潮流。
- $\rho_t$：作为成本权重，影响「何时充放更划算」。

## 四、控制变量（决策量）

设**放电为正**、**充电为负**（约定与功率平衡式需一致）：

$$
P_B(t)
$$

- $P_B(t) > 0$：放电（向母线注入有功）
- $P_B(t) < 0$：充电（从母线吸收有功）

### 功率限幅

$$
P_B^{\min} \le P_B(t) \le P_B^{\max}
$$

例如：$P_B \in [-100,\,100]\ \mathrm{kW}$（上下限对称时，放电上限为正、充电为负）。

## 五、状态更新（SOC 演化）

在时间步长 $\Delta t$、额定能量 $E_B$（$\mathrm{kWh}$）与综合效率 $\eta \in (0,1]$ 下，若 **$P_B>0$ 表示放电、SOC 下降**，可采用统一写法：

$$
\mathrm{SOC}_t = \mathrm{SOC}_{t-1} - \frac{\eta\, P_B(t)\, \Delta t}{E_B}
$$

$P_B(t)<0$（充电）时，上式右边第二项为负，$\mathrm{SOC}$ **上升**，与物理一致。若充放电效率需分开建模，可改为 $\eta_{\mathrm{ch}}$、$\eta_{\mathrm{dis}}$ 分段或 $\min/\max$ 形式，此处从略。

| 符号 | 含义 |
| ---- | ---- |
| $\mathrm{SOC}_t$ | 当前相对电量 |
| $\eta$ | 等效充放效率（标量近似） |
| $P_B(t)$ | 储能功率（正放负充） |
| $\Delta t$ | 时间步长 |
| $E_B$ | 额定能量容量 |

**数值例**：$\mathrm{SOC}_{t-1}=0.5$，$E_B=100\ \mathrm{kWh}$，$P_B(t)=-20\ \mathrm{kW}$（充电），$\Delta t=1\ \mathrm{h}$，$\eta=0.95$：

$$
\mathrm{SOC}_t = 0.5 - \frac{0.95 \times (-20) \times 1}{100} = 0.69
$$

## 六、目标函数（购电成本）

在简单购电成本模型下，目标可写为：

$$
\min \sum_t \rho_t \, P_{\mathrm{grid}}(t)\,\Delta t
$$

其中购电功率需与**功率平衡**一致。若采用上文 $P_B$ 符号（正为放电），一种常用写法为：

$$
P_{\mathrm{grid}}(t) = P_D(t) - P_{\mathrm{PV}}(t) - P_B(t)
$$

即：负荷由光伏、电网与储能共同满足；**放电**（$P_B>0$）减少购电，**充电**（$P_B<0$）增加购电。

**例**：$P_D=200\ \mathrm{kW}$，$P_{\mathrm{PV}}=80\ \mathrm{kW}$，$P_B=-50\ \mathrm{kW}$（充电），则

$$
P_{\mathrm{grid}} = 200 - 80 - (-50) = 170\ \mathrm{kW},\quad
\text{时段成本} \propto \rho \times 170
$$

（若目标以能量计费，需再乘 $\Delta t$ 与电价单位一致。）

## 七、约束摘要

| 类型 | 表述 |
| ---- | ---- |
| SOC | $ SOC_{\min} \le SOC_t \le SOC_{\max}$ |
| 储能功率 | $P_B^{\min} \le P_B(t) \le P_B^{\max}$ |
| 电压（可选） | $V_{\min} \le V_i(t) \le V_{\max}$（如 $0.95$–$1.05\ \mathrm{pu}$） |
| 线路电流（可选） | $I_\ell(t) \le I_{\ell,\max}$ |

实际 EMS 还会加入**爬坡**、**循环寿命**、**并网点功率因数**、**市场规则**等；上表是教学用最小集合。

## 八、工程中的数据形态

滚动优化或仿真流水线里，一帧数据常类似：

| time | load | pv | price | soc | Output ($P_B$) |
| ---- | ---- | -- | ----- | --- | ---------------- |
| $t_1$ | 220 | 40 | 0.25 | 0.50 | $-40$ |
| $t_2$ | 210 | 50 | 0.24 | 0.52 | $-30$ |
| $t_3$ | 230 | 60 | 0.27 | 0.54 | $20$ |

后续用状态更新方程更新 $\mathrm{SOC}$，并检查约束。

## 九、小结

| 角色 | 内容 |
| ---- | ---- |
| 输入 | 负荷、光伏、电价；初值 $\mathrm{SOC}_0$ |
| 状态 | 如 $s_t = [P_{\mathrm{net}}(t), \rho_t, \mathrm{SOC}_t]$ |
| 控制量 | $P_B(t)$（正放负充，与功率平衡一致） |
| 目标 | 最小化购电（或综合运行）成本 |
| 约束 | SOC、功率；扩展至电压、电流与其它运行规则 |

以上给出了与**线性/混合整数规划**、**模型预测控制（MPC）**或**强化学习**对接时最常用的「骨架」；在具体项目中只需替换为**你的节点潮流、效率曲线与市场结算**即可。
